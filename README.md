## `05.` Featured Projects

<details open>
<summary><b>🛰️ AstroViz — NASA Space Apps Challenge 2025 ("Meteor Madness")</b></summary>
<br/>

A 3D interactive web platform that uses real NASA Near-Earth Object (NEO) data and USGS datasets to simulate and visualize asteroid impact scenarios on Earth, built to make planetary defense science understandable for students, educators, and policymakers.

**Tech Stack:** `React.js (Vite)` `Three.js` `React Three Fiber` `Drei` `TailwindCSS` `Framer Motion` `Leaflet.js` `Zustand` `NASA NEO API` `USGS Data`

**What I Built**
- A real-time 3D interactive simulation that fetches live asteroid data from the NASA NEO API
- Trajectory, velocity, and potential impact effect simulations
- Visualizations for crater formation, energy release, and seismic impact
- An interactive module to test deflection strategies (kinetic and nuclear impact)
- Interactive 2D impact-zone maps using Leaflet.js, combined with geospatial USGS data

**Key Technical Features**
- 3D rendering pipeline built with Three.js, React Three Fiber, and Drei
- Lightweight global state management using Zustand
- Responsive, animated UI with TailwindCSS and Framer Motion
- Live data integration from NASA and USGS APIs

🏆 Awarded **Best Galactic Impact Award** at the NASA Space Apps Challenge 2025

🔗 [Repository](https://github.com/charan-135/astroviz-main)
